## 🌟 서비스 개요

Re:Buy는 소비자들이 일상에서 쉽게 친환경 제품을 구매하고, 탄소중립 실천에 참여할 수 있도록 돕는 종합 플랫폼입니다.

### 핵심 기능
1. **AI 맞춤형 추천**: 사용자의 과거 구매 패턴을 분석하여 개인화된 친환경 제품 추천
2. **크레딧 시스템**: 구매 금액의 5%를 크레딧으로 적립하여 다음 구매 시 사용 가능
3. **환경 기여도 분석**: 월별 구매 통계와 탄소 절감량, 환경 기여도를 시각화

사용자는 단순히 제품을 구매하는 것을 넘어, 자신의 소비가 환경에 미치는 긍정적 영향을 직관적으로 확인할 수 있습니다.

### 핵심 가치
- 🤖 **AI 기반 맞춤형 추천**으로 개인화된 친환경 쇼핑 경험 제공
- 💳 **크레딧 시스템**을 통한 지속적인 친환경 소비 유도
- 📊 **환경 기여도 시각화**로 소비자의 긍정적 영향력 확인
- 🌱 **지역 환경 활동 연계**로 온·오프라인 통합 경험 제공

## 🎯 타 서비스와의 차별점

1. **AI 기반 개인화 추천**
   - Upstage Solar-Pro2를 활용한 구매 패턴 분석
   - 사용자별 맞춤형 친환경 상품 추천
   - 월별 녹색 소비 리포트 자동 생성

2. **선순환 크레딧 시스템**
   - 구매 → 적립 → 재구매의 지속 가능한 소비 사이클
   - 환경 활동 참여를 통한 추가 크레딧 획득
   - 게이미피케이션을 통한 지속적인 참여 유도

3. **환경 영향 시각화**
   - 개인의 탄소 절감량을 직관적인 대시보드로 제공
   - 월별/연도별 환경 기여도 분석
   - 물 절약량, 나무 보호량 등 구체적 수치 제공

4. **오프라인 활동 연계**
   - 플로깅 등 지역 환경 활동 참여 시스템
   - 활동 인증샷 업로드 및 관리자 승인
   - 참여에 따른 크레딧 보상

5. **통합 경험 제공**
   - 상품 구매부터 활동 참여, 환경 기여도 분석까지 원스톱 서비스
   - 일관된 사용자 경험(UX)과 직관적인 인터페이스
   - 모바일/데스크톱 완벽 대응

## 🛠️ 구현 방식

### Frontend
**기술**: TypeScript와 React 18을 기반으로 구현하였으며, Vite를 빌드 도구로 사용하여 빠른 개발 환경을 구축했습니다.

**주요 구현**:
- Tailwind CSS로 일관된 디자인 시스템 적용
- React Router 6로 SPA 라우팅 구현
- Axios를 통해 RESTful API와 통신
- Context API로 전역 상태(인증, 장바구니 등) 관리
- React Icons를 활용한 직관적인 UI

### Backend
**기술**: Java 17과 Spring Boot 3.2.1을 사용하여 RESTful API 서버를 구축했습니다.

**주요 구현**:
- Spring Data JPA로 데이터 영속성 관리
- Spring Security와 JWT로 인증/인가 처리
- WebFlux를 활용해 Upstage AI API와의 비동기 통신 구현
- Swagger/OpenAPI 3.0으로 API 문서 자동화
- JUnit 5와 Mockito로 단위 테스트 작성

### Database
**기술**: PostgreSQL 15를 주 데이터베이스로 사용하며, Redis 7.x를 세션 및 캐시 관리에 활용합니다.

**주요 구현**:
- JPA Entity 설계 및 연관관계 매핑
- 인덱스 최적화로 쿼리 성능 개선
- 트랜잭션 관리 및 데이터 무결성 보장

### AI Integration
**기술**: Upstage Solar-Pro2 모델을 활용하여 AI 기능을 구현했습니다.

**주요 구현**:
- 사용자 구매 패턴 분석 및 맞춤형 상품 추천
- 월별 환경 리포트 자동 생성
- WebFlux 기반 비동기 API 통신으로 응답 속도 최적화

### 배포 및 DevOps
**기술**: Docker와 Docker Compose를 사용하여 컨테이너화했으며, GitHub Actions를 통한 CI/CD 파이프라인을 구축했습니다.

**배포 환경**:
- AWS EC2, ECS 등 다양한 클라우드 환경에 배포 가능
- Docker 이미지 자동 빌드 및 배포
- 환경별 설정 파일 분리 (dev, prod, local)
